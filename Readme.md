# Vereinskasse Server

API-Backend für die kleine Vereinskasse.
Screenshots und ausführliche Erläuterung folgen.


## Installation

- [.env](https://github.com/ZuttiWhv/vereinskasse-server/blob/development/docker/.env)
und [docker-compose.yml](https://github.com/ZuttiWhv/vereinskasse-server/blob/development/docker/docker-compose.yml)
herunterladen. 
- In der .env - Datei Einstellungen anpassen 
- docker compose up -d eingeben
